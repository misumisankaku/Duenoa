# スリーウェイ・デッドロック

かわいいファンタジーTCGのブラウザーゲームです。デッキは炎・大地・湖から選べます。各デッキ30枚で、CPU対戦と部屋コード式のオンライン対戦に対応しています。

## 対戦方法

- CPU対戦：デッキを選び、「コイントス」を押します。
- オンライン対戦：一方が「部屋を作る」を押してコードを共有します。相手はコードを入力して参加します。両者がデッキを選んだら、ホストがコイントスで開始します。
- 行動ログには、ドロー、ターン開始、召喚、呪文、攻撃先、ダメージなどが表示されます。

## オンライン通信

GitHub Pagesはゲーム画面の静的公開に使います。部屋コードの接続にはPeerJS Cloudのシグナリングを使い、対戦中のデータはブラウザー間でWebRTC接続します。プレイにはインターネット接続が必要です。

- [GitHub Pages](https://docs.github.com/en/pages)
- [PeerJS Cloud](https://peerjs.com/server/cloud)

## 公開

GitHub ActionsのPagesワークフローを使います。GitHub Pagesの公開元をGitHub Actionsに設定し、`main`へpushすると公開されます。
